# Conception : personas, fonctionnalités et stack technique

Démarche de design thinking pour repenser Learny autour des élèves du Burkina Faso.

Ouvrir [`index.html`](index.html) dans un navigateur. La page contient :

- le constat sur l'app actuelle (programme, couverture des niveaux, RAG, data, inscription) ;
- quatre proto-personas d'élèves (3e à Ouagadougou, Terminale D à Bobo-Dioulasso, élève déplacée, 6e en zone rurale) et leur entourage ;
- le parcours d'une journée de révision ;
- six problèmes à résoudre, seize idées et leur priorisation valeur / effort ;
- quatre écrans maquettés avec leurs textes ;
- une feuille de route en trois étapes, de « BEPC prêt » à toute la communauté ;
- le plan de recherche terrain pour valider les personas ;
- la stack recommandée pour un hébergement mutualisé o2switch.

Les personas sont des hypothèses : aucun élève n'a encore été interrogé.
